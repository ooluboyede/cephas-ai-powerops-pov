Security architecture requirements

✓ OIDC/MFA, RBAC and attribute-based access

✓ Signed tamper-evident audit events

✓ Encryption in transit and at rest

✓ Signed annual licence with public-key verification

✓ Customer-approved data residency and retention

Prototype limitation: this static PoV has no backend authentication, database, tenant isolation or cryptographic licensing. These are mandatory engineering gates before handling real customer data.
